CSS

What is CSS?

CSS (Cascading Style Sheets) controls how HTML content looks. It lets you set colors, fonts, spacing, borders, and page layouts. HTML provides the structure; CSS styles that structure.

CSS rules

A CSS rule has a selector, which chooses an HTML element, and declarations, which set its styles. Each declaration has a property and a value. 

h1 {
  color: teal;
  font-size: 2rem;
}

In this example, h1 is the selector, color and font-size are properties, and teal and 2rem are their values.

Common selectors

A type selector such as p selects all paragraphs. A class selector such as .card selects elements with class="card". An ID selector such as #header selects the element with id="header".

Adding CSS to a page

This website uses an external stylesheet. The link belongs inside the HTML <head>: 

<link rel="stylesheet" href="hr.css">

Keeping styles in a separate CSS file makes them easier to reuse and maintain across pages.
