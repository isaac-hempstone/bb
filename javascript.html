JavaScript

What is JavaScript?

JavaScript is a programming language that can make web pages interactive. It can respond to clicks, update page content, and work with data. HTML provides structure, CSS controls appearance, and JavaScript adds behavior.

Variables

Variables give names to values. Use const when you do not need to reassign a variable, and let when its value will change. 

const topic = "JavaScript";
let lessonsCompleted = 0;

lessonsCompleted = lessonsCompleted + 1;

Functions

A function is a reusable block of code. You can give it input values, called parameters, and have it return a result. 

function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Alex"));

Responding to a click

JavaScript can listen for events, such as a button click, and run code in response. This example updates text on the page: 

const button = document.querySelector("button");

button.addEventListener("click", function () {
  document.querySelector("p").textContent = "You clicked the button!";
});

Adding JavaScript to a page

JavaScript can be placed in a separate file and connected near the end of the HTML <body>: 

<script src="script.js"></script>

The src value should match the path and name of your JavaScript file.

JavaScript Libraries

JavaScript libraries are collections of pre-written code that make it easier to perform common tasks. Popular libraries include jQuery, React, and Lodash.

JavaScript Frameworks

JavaScript frameworks provide a structured way to build web applications. They often include tools for routing, state management, and building user interfaces. Popular frameworks include Angular, Vue, and Ember.

JavaScript and the DOM

The Document Object Model (DOM) is a representation of the HTML structure of a web page. JavaScript can manipulate the DOM to change the content, structure, and style of a page dynamically.

JavaScript and APIs

JavaScript can interact with APIs (Application Programming Interfaces) to fetch data from servers and display it on web pages. This allows developers to create dynamic and interactive web applications that can communicate with external services.
